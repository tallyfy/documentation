## Types of tasks in Tallyfy

Tallyfy has two categories of tasks - process tasks and one-off tasks - each supporting five step types.

### Process steps vs one-off tasks

*   **Process Steps/Tasks**: These are defined within a [template](/products/pro/documenting/templates/) as "Steps," and they become "Tasks" when the [process](/products/pro/tracking-and-tasks/processes/) runs.
*   **One-Off Tasks**: Standalone to-dos that aren't linked to any template.
    *   [Create one-off tasks individually](/products/pro/tracking-and-tasks/tasks/how-to-create-a-one-off-task-in-tallyfy/)
    *   [Add them to a running process](/products/pro/tracking-and-tasks/processes/edit-processes/how-can-i-add-tasks-to-active-processes-on-tallyfy/) as ad-hoc tasks
    *   Link a one-off task to a specific template or process

:::tip[Adding ad-hoc tasks to active processes]
You can add ad-hoc tasks to a running [process](/products/pro/tracking-and-tasks/processes/) without modifying the original [template](/products/pro/documenting/templates/).

Template creators control this via the **"Can people add one-off tasks to this process?"** toggle in the template editor (default is "Yes"). If it's set to "No," ad-hoc tasks are blocked entirely for that process.
:::

### Five step/task types

| Type                | Main Button(s)           | Must be completed? | Description |
|---------------------|--------------------------|--------------------|-------------|
| **Task**            | COMPLETE                 | Yes                | Standard to-do for most actions (data entry, reviews). |
| **Approve/Reject**  | APPROVE / REJECT         | Yes                | For decisions and approvals. Can trigger [Automations](/products/pro/documenting/templates/automations/). |
| **Expiring**        | ACKNOWLEDGE              | No, it completes itself at the deadline | Auto-completes at deadline if not acknowledged. Prevents overdue task build-up. |
| **Email Draft**     | SEND, or COMPLETE if you're the only recipient | Yes                | Email draft for assignee review/edit before manual send. |
| **Email Auto-Send** | SEND RIGHT NOW / (Auto)  | No, it sends and completes itself at the deadline | Sends email automatically at deadline, or earlier via **SEND RIGHT NOW**. |

#### Task type

The standard type. The assignee clicks **COMPLETE** to finish it.

#### Approve/Reject type

Shows two buttons - **APPROVE** and **REJECT**. Use [Automations](/products/pro/documenting/templates/automations/) to trigger different actions based on the choice.

:::tip[Restricting approvals]
You can restrict completion to assigned users only by enabling "Only assigned members can complete..." in the task's **Advanced** tab. Admins can always override this setting.
:::

#### Expiring type

If nobody clicks **ACKNOWLEDGE** by the deadline, the task auto-completes and disappears from active task lists. Great for information sharing without creating [task debt](/products/pro/tutorials/how-to/how-to-avoid-task-debt/).

Common uses:
- FYI updates that don't require action
- Optional resources or training materials
- Weekly status reports for awareness
- Non-critical announcements

Team members get notified and can engage if they want, but the task won't pile up if they don't.

#### Email types

*   **Email Auto-Send**: Write the email in the template. Tallyfy sends it to the people in its **To** field at the step's deadline, unless a member assigned to the step clicks **SEND RIGHT NOW** earlier. [What happens at the deadline](#what-happens-at-the-deadline) shows the timeline.
*   **Email Draft**: Write a draft in the template. The assignee reviews/edits and clicks **SEND** manually. If they're the only recipient, the button reads **COMPLETE** instead, and clicking it still sends the email.
*   **Send Chromeless**: Both email types can send without Tallyfy branding. Enable the **"Send Chromeless"** option to send plain emails without the Tallyfy logo, header, and footer - useful when emails should look like standard messages rather than workflow notifications.
*   **Email Copies**: Assignees receive a copy of sent emails unless they've disabled email notifications.
*   **Guests**: A guest assigned to an email step can't send it. On an email step in a process, they get the email when it's sent, with no button to open the task. Tallyfy doesn't send them an assignment email or a reminder for that step, and emails them about a comment on it only if the comment mentions them or they watch the step.

:::note[Receiving email copies]
Receiving copies depends on the "Receive emails when I'm assigned" setting under **Settings** > **My Account** > **Email Notifications**. See [Manage Email Notifications](/products/pro/settings/personal-settings/how-can-i-manage-email-notifications-in-tallyfy/).
:::

### Being told about a task, and doing it

Tallyfy emails you when a task becomes yours, whatever its deadline says. The deadline doesn't hold that email back, and it doesn't send you a reminder. It marks when the task is due, and when it starts to show as overdue.

For a Task, Approve/Reject or Expiring step, Tallyfy emails you that it's yours at one of these moments:

- **When a process launches**, if one or more of your steps are visible from the start.
- **When a rule shows a hidden step** that's assigned to you. For members, the subject starts with "It's your turn".
- **When someone assigns you** to a task that's already running.

Those emails need **Receive emails when I'm assigned** switched on in your [email notification settings](/products/pro/settings/personal-settings/how-can-i-manage-email-notifications-in-tallyfy/).

When an earlier step is completed and your deadline moves, you'll see the new date in Tallyfy, but no email goes out. There's no reminder email as your deadline gets close, or when it arrives.

Once a deadline passes, the task shows as overdue. Your digest email lists your overdue tasks first, then ones coming up, on the days you've chosen to get it. If someone needs a nudge sooner, you can [send a reminder by hand](/products/pro/tracking-and-tasks/tasks/how-can-i-send-email-reminders-in-tallyfy/). How the deadline itself is counted is in [how a step deadline is worked out](/products/pro/documenting/templates/edit-templates/step-timings/).

#### What happens at the deadline

Expiring and Email Auto-Send are the two step types that do something when their deadline arrives. Tallyfy checks for them every 5 minutes, so each one acts within about 5 minutes after its deadline.

If a step's deadline counts from another step that's still open, it waits. Once that step is completed, Tallyfy works the deadline out again from that moment, and the step acts when the new deadline passes.

An Expiring step, from the moment it becomes yours:

```d2
# Expiring step: what happens over time
direction: right

Yours: "Becomes yours, email sent" {
  style.fill: "#fff3cd"
  style.stroke: "#225930"
}

Ack: "Acknowledged early" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Due: "Deadline, no reminder" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Auto: "Completes as expired" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Yours -> Ack: Before the deadline {
  style.stroke: "#225930"
}
Yours -> Due: Not acknowledged {
  style.stroke: "#225930"
}
Due -> Auto: Within 5 minutes {
  style.stroke: "#225930"
}
```

**What to notice:**
- You're emailed when the step becomes yours. Tallyfy sends no reminder before the deadline.
- Any assignee can click **ACKNOWLEDGE** before the deadline, and the step is done at once.
- If nobody does, Tallyfy completes the step at the deadline and marks it expired.

An Email Auto-Send step:

```d2
# Email Auto-Send step: what happens over time
direction: right

Active: "Step becomes active" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Early: "SEND RIGHT NOW clicked" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Due: "Deadline arrives" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Sent: "Email sent, step done" {
  style.fill: "#fff3cd"
  style.stroke: "#225930"
}

Active -> Early: Optional {
  style.stroke: "#225930"
}
Early -> Sent: At once {
  style.stroke: "#225930"
}
Active -> Due: Nobody sends early {
  style.stroke: "#225930"
}
Due -> Sent: Within 5 minutes {
  style.stroke: "#225930"
}
```

**What to notice:**
- The recipients are the people in the step's **To** field.
- A member assigned to the step can click **SEND RIGHT NOW** to send it before the deadline.
- If nobody does, Tallyfy sends it to the recipients at the deadline, and the step completes itself.

## Types of tasks in Tallyfy

Every step in a Tallyfy template is a **Task**, a **Decision** or an **Email**. A Task is work someone does, a Decision asks someone to approve or reject, and an Email sends a message. Each kind has a switch or two that changes how the step finishes.

### Process steps vs one-off tasks

*   **Process Steps/Tasks**: These are defined within a [template](/products/pro/documenting/templates/) as "Steps," and they become "Tasks" when the [process](/products/pro/tracking-and-tasks/processes/) runs.
*   **One-Off Tasks**: Standalone to-dos that aren't linked to any template.
    *   [Create one-off tasks individually](/products/pro/tracking-and-tasks/tasks/how-to-create-a-one-off-task-in-tallyfy/)
    *   [Add them to a running process](/products/pro/tracking-and-tasks/processes/edit-processes/how-can-i-add-tasks-to-active-processes-on-tallyfy/) as ad-hoc tasks
    *   Link a one-off task to a specific template or process

:::tip[Adding ad-hoc tasks to active processes]
You can add ad-hoc tasks to a running [process](/products/pro/tracking-and-tasks/processes/) without modifying the original [template](/products/pro/documenting/templates/).

Template creators control this via the **"Can people add one-off tasks to this process?"** toggle in the template editor (default is "Yes"). If it's set to "No," ad-hoc tasks are blocked entirely for that process.
:::

### Three kinds of step

You pick a step's kind in the template editor. Open the step's **Edit step** panel and use its **Type** row, or click the step's number in the **Table** view. The switches for that kind show right under it.

| Kind | What it's for | Its switches |
|---|---|---|
| **Task** | Someone does the work, fills in any fields, then clicks **Complete**. | **Finishes by itself at the deadline if nobody does it**, and **Everyone assigned must finish** |
| **Decision** | Someone approves or rejects. Automations can take a different path for each answer. | **Everyone assigned must finish** |
| **Email** | Sends an email. Someone checks it and presses **Send**, or it goes out by itself on the deadline. | **When it goes out**, and **Send as a plain email** |

The Tasks page and the template's steps table name each step by its kind and switch, so you'll see five names:

| Name | Button on the task | Does someone have to finish it? | Old name |
|---|---|---|---|
| **Task** | **Complete** | Yes | Task |
| **Decision** | **Approve** and **Reject** | Yes | Approve/Reject |
| **Task, finishes itself** | **Acknowledge** | No, it completes itself at the deadline | Expiring |
| **Email** | **Send**, or **Complete** if you're the only recipient | Yes | Email Draft |
| **Email, sends itself** | **Send Right Now** | No, it sends and completes itself at the deadline | Email Auto-Send |

The old names still show in a few places, such as the **Type** menu of a one-off task.

#### Task

The standard kind. The assignee clicks **Complete** to finish it.

Turn on **Finishes by itself at the deadline if nobody does it** for something people should see but don't have to act on. Assignees can click **Acknowledge** once they've read it. If nobody does by the deadline, the task completes itself and drops off active task lists, so it doesn't pile up as [task debt](/products/pro/tutorials/how-to/how-to-avoid-task-debt/).

Common uses:
- FYI updates that don't require action
- Optional resources or training materials
- Weekly status reports for awareness
- Non-critical announcements

Team members get notified and can engage if they want, but the task won't pile up if they don't.

#### Decision

Shows two buttons, **Approve** and **Reject**. Use [automations](/products/pro/documenting/templates/automations/) to do something different for each answer, with the conditions **is approved** and **is rejected**.

:::tip[Restricting approvals]
You can restrict completion to assigned users only by enabling "Only assigned members can complete..." in the task's **Advanced** tab. Admins can always override this setting.
:::

#### Everyone assigned must finish

A Task or a Decision with several assignees normally finishes when one of them acts. Turn on **Everyone assigned must finish** and the step stays open until each assignee has done their part. The [Advanced tab](/products/pro/tracking-and-tasks/tasks/how-can-i-utilize-tallyfys-advanced-tab-features/) shows the same setting as **All assignees must complete this task**.

A Task that finishes itself doesn't have this switch. Changing a step to a Decision turns the switch off, and you can turn it back on. On the Docs, Basic and free plans you can't change it.

#### Email types

An Email step sends a message you write in the template. The people you pick for it are its **To**, the people who get the email.

*   **When it goes out**: Pick **Someone checks it and presses Send** or **Sends itself on the deadline**.
    *   **Someone checks it and presses Send**: A member in **To** reviews the email, edits it if needed, and clicks **Send**. If they're the only recipient, the button reads **Complete** instead, and clicking it still sends the email. The Tasks page calls this an **Email**. It used to be called Email Draft.
    *   **Sends itself on the deadline**: Tallyfy sends the email to the people in **To** at the step's deadline, unless a member assigned to the step clicks **Send Right Now** earlier. The Tasks page calls this **Email, sends itself**. It used to be called Email Auto-Send. [What happens at the deadline](#what-happens-at-the-deadline) shows the timeline.
*   **Send as a plain email**: On by default for a new Email step. The email arrives as a plain message, without Tallyfy's styled layout. Turn it off and it arrives inside a styled email with your logo at the top. The Tasks page's task panel and the one-off task dialog still call the same setting **Send Chromeless**.
*   **Summary**: Under the switches, a short summary says who gets the email and when it goes out. With **Send as a plain email** on, it starts "The people in To get this email and nothing else: no task and no reminders." The second line is "It goes out when someone presses Send." or "It goes out on the deadline."
*   **Email Copies**: Assignees receive a copy of sent emails unless they've disabled email notifications.
*   **Guests**: A guest assigned to an email step can't send it. On an email step in a process, they get the email when it's sent, with no button to open the task. Tallyfy doesn't send them an assignment email or a reminder for that step, and emails them about a comment on it only if the comment mentions them or they watch the step.

:::note[Receiving email copies]
Receiving copies depends on the "Receive emails when I'm assigned" setting under **Settings** > **My Account** > **Email Notifications**. See [Manage Email Notifications](/products/pro/settings/personal-settings/how-can-i-manage-email-notifications-in-tallyfy/).
:::

### Being told about a task, and doing it

Tallyfy emails you when a task becomes yours, whatever its deadline says. The deadline doesn't hold that email back, and it doesn't send you a reminder. It marks when the task is due, and when it starts to show as overdue.

For a Task or a Decision, including a Task that finishes itself, Tallyfy emails you that it's yours at one of these moments:

- **When a process launches**, if one or more of your steps are visible from the start.
- **When a rule shows a hidden step** that's assigned to you. For members, the subject starts with "It's your turn".
- **When someone assigns you** to a task that's already running.

Those emails need **Receive emails when I'm assigned** switched on in your [email notification settings](/products/pro/settings/personal-settings/how-can-i-manage-email-notifications-in-tallyfy/).

When an earlier step is completed and your deadline moves, you'll see the new date in Tallyfy, but no email goes out. There's no reminder email as your deadline gets close, or when it arrives.

Once a deadline passes, the task shows as overdue. Your digest email lists your overdue tasks first, then ones coming up, on the days you've chosen to get it. If someone needs a nudge sooner, you can [send a reminder by hand](/products/pro/tracking-and-tasks/tasks/how-can-i-send-email-reminders-in-tallyfy/). How the deadline itself is counted is in [how a step deadline is worked out](/products/pro/documenting/templates/edit-templates/step-timings/).

#### What happens at the deadline

A Task that finishes itself and an Email that sends itself are the two types that do something when their deadline arrives. Tallyfy checks for them every 5 minutes, so each one acts within about 5 minutes after its deadline.

If a step's deadline counts from another step that's still open, it waits. Once that step is completed, Tallyfy works the deadline out again from that moment, and the step acts when the new deadline passes.

A Task that finishes itself, from the moment it becomes yours:

```d2
# Task that finishes itself: what happens over time
direction: down

Yours: "Becomes yours\nEmail sent" {
  style.fill: "#fff3cd"
  style.stroke: "#225930"
}

Ack: "Acknowledged\nearly" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Due: "Deadline\nNo reminder" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Auto: "Completes\nas expired" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Yours -> Ack: "Before the\ndeadline" {
  style.stroke: "#225930"
}
Yours -> Due: "Not\nacknowledged" {
  style.stroke: "#225930"
}
Due -> Auto: "Within\n5 minutes" {
  style.stroke: "#225930"
}
```

**What to notice:**
- You're emailed when the step becomes yours. Tallyfy sends no reminder before the deadline.
- Any assignee can click **Acknowledge** before the deadline, and the step is done at once.
- If nobody does, Tallyfy completes the step at the deadline and marks it expired.

An Email that sends itself:

```d2
# Email that sends itself: what happens over time
direction: down

Active: "Step becomes\nactive" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Early: "Send Right Now\nclicked" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Due: "Deadline\narrives" {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Sent: "Email sent\nStep done" {
  style.fill: "#fff3cd"
  style.stroke: "#225930"
}

Active -> Early: Optional {
  style.stroke: "#225930"
}
Early -> Sent: At once {
  style.stroke: "#225930"
}
Active -> Due: "Nobody\nsends early" {
  style.stroke: "#225930"
}
Due -> Sent: "Within\n5 minutes" {
  style.stroke: "#225930"
}
```

**What to notice:**
- The recipients are the people in the step's **To** field.
- A member assigned to the step can click **Send Right Now** to send it before the deadline.
- If nobody does, Tallyfy sends it to the recipients at the deadline, and the step completes itself.

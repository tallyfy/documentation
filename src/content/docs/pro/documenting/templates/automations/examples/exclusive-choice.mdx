## Exclusive choice - pick one path

Exclusive choice automation sends your process down exactly **one** path from multiple options based on a condition.

![BPMN diagram showing exclusive choice gateway with Path A or Path B branching options](https://screenshots.tallyfy.com/tallyfy/pro/bpmn-exclusive-choice-gateway.png)
*(Choose Path A OR Path B - not both)*

You set up several [automations](/products/pro/documenting/templates/automations/), each with its own condition. When a process launches or someone completes a task, Tallyfy checks the conditions and runs every automation whose condition is true.

### Example - different onboarding steps by role

Say you're onboarding new employees in one [process](/products/pro/tracking-and-tasks/processes/). Field workers need safety training and equipment setup. Office workers need IT access and desk assignments.

Add a step asking for the employee's role using a **Radio Button** [form field](/products/pro/tracking-and-tasks/tasks/what-are-form-fields-in-tallyfy/) (radio buttons only allow *one* selection).

![Role selection step with radio button form field](https://screenshots.tallyfy.com/tallyfy/pro/desktop-light-role-selection.png)

In the template, turn on **Hide by default** for the four role steps: Safety training, Equipment setup, IT access and Desk assignment. Steps are visible unless you hide them. Without this setting, every new employee would see all four.

Then create two [automations](/products/pro/documenting/templates/automations/) using [visibility actions](/products/pro/documenting/templates/automations/actions/visibility-actions/)[^1]:

- **Automation 1:**
  ```automation
  AUTOMATION Show the field worker steps
  IF field "Role" is "Field worker"
  THEN show "Safety training"
  AND show "Equipment setup"
  ```
  ![The field worker automation, showing its condition and the steps it reveals](https://screenshots.tallyfy.com/tallyfy/pro/desktop-light-ifcompleted-automation-example.png)

- **Automation 2:**
  ```automation
  AUTOMATION Show the office worker steps
  IF field "Role" is "Office worker"
  THEN show "IT access"
  AND show "Desk assignment"
  ```
  ![The office worker automation, showing its condition and the steps it reveals](https://screenshots.tallyfy.com/tallyfy/pro/desktop-light-office-worker-exclusive-choice.png)

The Role field can only hold *one* value, so only *one* automation fires when the role step is completed. A field worker gets Safety training and Equipment setup, and the office steps stay hidden. An office worker gets IT access and Desk assignment instead.

Use conditions that can't be true at the same time, like the options of one radio button field. If two conditions can both be true, both automations run and both sets of steps appear.

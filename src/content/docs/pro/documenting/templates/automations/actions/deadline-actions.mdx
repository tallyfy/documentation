## Deadline actions

Deadline actions adjust task due dates automatically when an automation's conditions are met. You can:

- Shift a deadline forward or backward by a set amount (e.g. +3 days)
- Base a deadline on another step's due date
- Set a deadline from a date entered in a [form field](/products/pro/tracking-and-tasks/tasks/what-are-form-fields-in-tallyfy/)

Use the **Apply to** dropdown in your automation to pick which step's deadline changes.

Deadline is one of five action types you can add to an [automation](/products/pro/documenting/templates/automations/). The others toggle [visibility](/products/pro/documenting/templates/automations/actions/visibility-actions/), [reopen steps](/products/pro/documenting/templates/automations/actions/status-actions/), update [assignments](/products/pro/documenting/templates/automations/actions/asignment-actions/), and fire a webhook.

:::caution[A deadline action runs once per process, and then it's done]
Tallyfy runs each automation at most once in a given process. Once a deadline action has fired,
the date it set stays put. Change the form field it counted from afterwards and the deadline
does not move, because the automation won't run a second time.

That matters most when a date you're counting from is the kind that slips, like a hire date or
an event date. Read [when an automation
runs](/products/pro/documenting/templates/automations/when-automations-run/) before you build a
template around one, and adjust the deadlines by hand if the date moves mid-process.
:::

### Examples of deadline actions

Here's how deadline actions work in practice.

**Example 1:** Make deadline earlier for premium service
```automation
AUTOMATION Make deadline earlier for premium service
IF field "Package Purchased" is "Premium"
THEN shift deadline of "Send First Draft" by 3 days before its own deadline
```

**Example 2:** Set deadline from a form field date
```automation
AUTOMATION Set deadline from a form field date
IF field "Project Scope" is "Complex"
THEN shift deadline of "Review Meeting" by 5 days from field "Client Kick-off Date"
```
The review meeting deadline lands 5 days[^1] after whatever date the user entered in the "Client Kick-off Date" field.

**Example 3:** Link deadlines between tasks
```automation
AUTOMATION Link deadlines between tasks
IF step "Initial Review" is completed
THEN shift deadline of "Final Approval" by 2 days from step "Client Feedback"
```
Final approval falls 2 days after the client feedback step was due.

![Deadline automation example showing step 13 deadline shift](https://screenshots.tallyfy.com/tallyfy%2Fpro%2Fdesktop-light-deadline-automation-example.png)

Step 13's deadline gets pushed 1 day later when the condition is met.

### What a deadline action counts from

Every deadline action needs a starting point. There are exactly three, and you pick one when you
build the action.

```d2
# The three starting points a deadline action can count from
direction: right

Base: Starting point {
  shape: diamond
  style.fill: "#f2faf4"
  style.stroke: "#225930"
}

Own: This step's due date {
  shape: rectangle
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Step: Another step due date {
  shape: rectangle
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Field: A date form field {
  shape: rectangle
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

New: New deadline {
  shape: rectangle
  style.fill: "#fff3cd"
  style.stroke: "#225930"
}

Base -> Own
Base -> Step
Base -> Field
Own -> New: Gap, after or before {
  style.stroke: "#225930"
}
Step -> New: Gap, after or before {
  style.stroke: "#225930"
}
Field -> New: Gap, after or before {
  style.stroke: "#225930"
}
```

- **Current deadline** - add to or subtract from the target step's existing due date
- **Another step's deadline** - count from a different step's due date
- **Date field value** - count from a date somebody entered in a form field

Want Step B due 2 days after Step A? Set it as "+2 days from Step A's deadline."

The form field has to be a **Date** field. Tallyfy won't let you save a deadline action pointed
at a text or number field, so if the date you need is being typed into a text box, change the
field type first.

There's no option to count from the process launch. If that's what you want, set it on the step
itself in the [Timings row](/products/pro/documenting/templates/edit-templates/step-timings/)
rather than in an automation.

:::caution[Deadline actions ignore your work week]
Your organization's working days and hours are applied when a task is first created, when you
change a deadline by hand, and when a deadline moves because the step it counts from moved. They
are **not** applied to a deadline set by an automation.

So an automation can land a deadline on a Saturday, or at 3am, in an organization set to
Monday through Friday, 9 to 5. The date is whatever the arithmetic produced. Bear that in mind
when you pick a gap, and check the result near a weekend.

Tallyfy counts in calendar days throughout, and it doesn't know about public holidays or
individual time off anywhere. See [customize work week](/products/pro/settings/org-settings/how-to-adjust-task-deadlines-to-work-week/)
for where the work week does apply.
:::

:::tip[Calendar-based vs relative deadlines]
Tallyfy deadlines are relative to when the process starts[^2], not calendar-based. If you need deadlines on specific days (like every Monday):

1. **Weekly patterns** - schedule process launches on those days, then use relative deadlines
2. **Monthly patterns** - use scheduled launches on specific dates
3. **Accounting cycles** - consider separate templates for different deadline patterns
4. **Variable deadlines** - use date form fields to capture dates, then set deadlines relative to them
:::

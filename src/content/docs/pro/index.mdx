### Problems Tallyfy solves

* **Start quick** - AI creates or imports processes in minutes.
* **Run it - don't read it** - Nobody has to read and remember everything. Everyone follows the latest process.
* **Prevent mistakes** - Stop tasks from being forgotten or done a different way each time. Nothing falls through the cracks.
* **Track it** - Track any process in real-time. No more manual status updates and meetings.
* **Improve it** - Improve your process easily. Automate certain tasks.
* **Delegate** - Hand work to people, automation, or AI automatically. Grow your operations and your margins while quality improves.

That's a massive waste hiding in plain sight.

You can't hand tasks to AI without agreed processes that people already follow. Without standardized processes, AI becomes guesswork. Tallyfy gives AI the foundation it needs to be useful in practice.

## How Tallyfy works

Three steps: document your processes, track them as live workflows, then improve them over time.

### 1. Document

Tallyfy keeps all your business procedures in one place, right where they're used: inside active workflows. Capture every task, how to do it, who's doing it, and by when. Write your process down in minutes, like a recipe. AI can draft it, or you can import the SOPs you already have.

### 2. Track

Turn what you wrote down into a running workflow right away. Launch it with one click, and the process runs itself. Track [task](/products/pro/tracking-and-tasks/tasks/) progress and capture data in real time (clients love this). You see every step, whether a person or AI does it. Tallyfy handles reminders automatically. Everyone can see where each workflow stands, so you don't need a status meeting to find out. You can assign work to your clients, and they can see progress too.

### 3. Improve

Hand selected tasks to [automations](/products/pro/documenting/templates/automations/), scripts, or AI. You do it with simple "if this then that" automations that any business user can set up. Each improvement to a process you repeat keeps adding value over time. You can't improve or automate chaos. Tallyfy makes processes visible and measurable.

## Best-fit processes


Tallyfy works best for workflows that:

-   **Need structured data**: You collect the same information every time.
-   **Are frequent**: They happen often enough to be worth making digital.
-   **Require standardization**: They must be done the same way each time.
-   **Need to scale**: Set them up correctly now, and they handle higher volumes later.
-   **Are complex**: They have many steps or conditional paths that are hard to remember.
-   **Require audit trails**: You need proof of who completed what.
-   **Need tracking**: Workers, managers, leaders, or customers need to see progress.
-   **Must be predictable**: Everyone knows what happened and what's next.

### Key benefits

Many business processes live in email, chat, and spreadsheets. Tallyfy replaces that mess with workflows that run themselves:

- **Less admin** - No more status updates and follow-ups.
- **Consistency** - Every process follows your best practice.
- **Client transparency** - Share live progress outside your company with client-facing workflows that impress.
- **Zero dropped balls** - Automatic handoffs don't fail.
- **Steady improvement** - Improvements based on data build on each other.
- **Set up once** - Turn processes into reusable [templates](/products/pro/documenting/templates/).
- **Fewer follow-up emails** - Notifications happen automatically.

### Unique features

- **Client-facing workflows** that make money, not just save money.
- **[Knowledge-only mode](/products/pro/tutorials/knowledge-only-mode/)** - Publish procedures as searchable reference guides without tracking. Perfect for how-to documentation and SOPs that teams need to read but don't formally complete.
- **[Conditional logic automation](/products/pro/documenting/templates/automations/conditional-visibility-guide/)** - Show or hide tasks based on form inputs. The workflow adapts to what each user selects.[^2]
- **No-code automation** anyone can set up. It covers conditional branching, auto-assignments, and deadline actions.

## Getting started

Get your first workflow running:

<Steps>
1.  **Document and centralize.** Create [templates](/products/pro/documenting/templates/) using AI or import existing documents. Centralize your SOPs.
2.  **Launch and track.** Launch templates as active [processes](/products/pro/tracking-and-tasks/processes/). Track completion and assign [tasks](/products/pro/tracking-and-tasks/tasks/).
3.  **Automate and improve.** Add [automations](/products/pro/documenting/templates/automations/). Use [analytics](/products/pro/integrations/analytics/) to refine your templates.
</Steps>

:::tip[New user onboarding]
**First time using Tallyfy?** Tallyfy automatically launches an onboarding process with sample tasks to complete. The first task asks you to mark it complete. Just click the **Complete** button in that task. If the **Start Process** button appears grayed out, complete the onboarding tasks first. This helps you understand the basics before launching your own processes.
:::

### 1. Create a template

[Templates](/products/pro/documenting/templates/) are your workflow blueprints in Tallyfy:

- Create with AI.
- Import existing SOPs instantly.
- Start from proven examples.

Two types cover everything:
- **[Procedure templates](/products/pro/documenting/templates/)** - Multi-step workflows, with an owner and a deadline on each task.
- **[Document templates](/products/pro/documenting/documents/)** - Smart forms with automatic [routing](/products/pro/tracking-and-tasks/tasks/what-are-form-fields-in-tallyfy/).[^3]


![Example template in Tallyfy showing workflow steps](https://screenshots.tallyfy.com/tallyfy%2Fpro%2Fdesktop-light-show-template-example.png)

### 2. Launch processes

Launch live workflows called [processes](/products/pro/tracking-and-tasks/processes/). It's that simple:

<Steps>
1. Pick your template.
2. Name it clearly ("Samsung Onboarding - Q4 2024").
3. Fill in the quick kick-off form.
4. Tallyfy auto-assigns the right people.
5. Click launch. Done!
</Steps>

### 3. Track progress

Once a process is running:
- Each [task](/products/pro/tracking-and-tasks/tasks/) goes to the people, groups or job titles set in the template, or to whoever an automation assigns.
- People get email notifications and reminders about their own tasks.
- Anyone with access can follow progress in the [tracker view](/products/pro/tracking-and-tasks/tracker-view/).

## Comparison to traditional tools

### Document tools

Word, Google Docs, wikis, and Notion create static documentation. Here's how Tallyfy's active workflows compare:

| Static Documentation | Tallyfy Active Workflows |
|---------------------|-------------------------|
| Reads like a manual | Runs like software |
| People must remember to check | Notifications bring work to people |
| No accountability tracking | See exactly who did what, when |
| Manual status updates | Real-time progress visibility |
| Copy-paste for each use | Launch once, runs automatically |
| Hope people follow it | Enforces the process |
| Separate tools for forms | Forms built into workflow |
| Email chains for approvals | Approvals happen in-context |

Key differences:
- Launch as live processes - not PDFs nobody reads.
- Tasks happen inside the workflow with assignments and deadlines.
- [Snippets](/products/pro/documenting/templates/snippets/) eliminate copy-paste.[^4]
- [Translates](/products/pro/miscellaneous/how-can-i-translate-content-in-tallyfy/) content into each person's language once an admin sets it up.[^5]
- Template updates apply to every process you launch next.
- See who actually follows procedures.
- Collect data through forms at each step.
- Automate handoffs and routing decisions.

### Spreadsheets

Key differences:
- Workflows that run themselves (not manual tracking).
- One source of truth. No more "v2_final_FINAL.xlsx".
- Guests see only their tasks.
- If-this-then-that automation built in.
- Clients love the real-time visibility.

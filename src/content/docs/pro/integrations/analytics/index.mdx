## Tallyfy Analytics overview

Tallyfy Analytics is a paid add-on that copies your workflow data into a private Amazon Athena[^1] environment, where you can query it with SQL.

You can connect BI tools like Tableau, Power BI, and Looker directly to your Tallyfy data. Use them to build reports that Tallyfy's own screens don't offer, such as process trends over many months or the steps where tasks get stuck.

:::note[Do you actually need a dashboard?]
For one-time or exploratory questions, asking Claude through the Tallyfy MCP server is often faster than building a report. See [one-time questions vs recurring dashboards](/products/pro/integrations/analytics/one-time-questions-vs-recurring-dashboards/) to choose the right approach.
:::

### Key features

- **Full process data access** - each process's status and owner, every task with its assignees and due dates, form field answers, and comments.
- **SQL query capabilities** - write SQL to join tables, aggregate metrics, and filter by date range.
- **BI tool integration** - works with tools that connect to Amazon Athena, including Power BI, Tableau, and Looker. Sigma Computing can't connect to Athena directly, so it [needs a workaround](/products/pro/integrations/analytics/sigma/).
- **Custom dashboards** - build your own reports in your BI tool, and combine Tallyfy data with data from your other systems.
- **Trend analysis** - compare how your processes change from month to month. Your data stays available for as long as you keep the add-on.

### Operational details

- **Add-on service** - priced per seat, per year, on every committed seat (full and light). See [billing add-ons and usage credit](/products/pro/settings/billing/billing-add-ons-and-usage-credit/) for how it's charged.
- **Private infrastructure** - your data lives in its own Amazon Athena environment. No other accounts can access it.

### Tracking time spent on tasks

Tallyfy Analytics automatically records when each task was assigned and completed. That shows elapsed calendar time, not how long someone actually worked on the task. To capture real effort time, add time tracking form fields. See [how to track time spent on tasks](/products/pro/tutorials/how-to/track-time-in-tasks/) for how to set them up.

:::note[Loading past processes]
Tallyfy can load your past processes as well as new ones when it sets up Analytics. Ask support if you want history from a particular date.
:::

:::note[Timestamp handling in Analytics]
Timestamps in Tallyfy Analytics use the format `YYYY-MM-DD HH:MM:SS`[^2], for example `2024-03-15 14:30:00`, with no timezone. They are UTC. In Tallyfy's interface, these timestamps are converted to each user's personal timezone setting.
:::

### Security credentials

Once Tallyfy activates Analytics for you, you'll receive two sets of credentials:

1. **AWS console login** - a username and password for signing in to the AWS web console. It works in the console only, not in BI tools.
2. **API Access Key and Secret Key pair** - these connect your BI tools to the data. You'll paste them into Power BI, Tableau, or whatever tool you use.

### Getting started

To turn on Tallyfy Analytics, ask Tallyfy support or your account manager. There's no switch for it in your own settings. Tallyfy sets it up and then sends you your credentials.

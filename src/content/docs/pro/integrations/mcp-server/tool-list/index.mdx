## What your AI can actually do

The Tallyfy MCP server gives a connected AI **115 tools**. This page lists all of them.

**You do not need this page to use Tallyfy with AI.** You ask in plain language and your assistant
picks the right tool. This is here for when you need to check exactly what an AI can and cannot do
in your account, which comes up when you are writing an internal policy, reviewing an audit trail,
or deciding whether to connect AI at all.

:::note[Read only against can change things]
**50 of the 115 tools only read.** They cannot alter anything. The rest can change your account,
and each one is marked below. An AI still acts as you, with your permissions, so it can never do
anything you could not do yourself.
:::

**Legend.** **Reads** means the tool only looks and cannot alter anything. **Adds** means it only
creates or appends. **Changes or removes** means it can overwrite or delete something that is
already there, so those are the ones worth reading closely.

## Keeping this honest

This list is generated from the running production server rather than written by hand, so it says
what the server actually offers rather than what somebody remembered. If you find a tool here that
does not exist, or one missing, that is a bug worth telling us about.

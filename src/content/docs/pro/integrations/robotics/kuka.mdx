## Where a written procedure fits around a KUKA robot

KUKA robots do the moving, and KUKA's own software programs them and watches the fleet. The steps people take around the robot are a separate matter: who checks the cell before a run, who approves a changeover and who signs off after a fault. A Tallyfy [template](/products/pro/documenting/templates/) could hold those steps.

Outside software can read a KUKA robot's status. Sending it work takes an add-on package that KUKA sells.

## What outside software can and can't do

### Reading a robot's status

The [OPC Foundation listing](https://opcfoundation.org/products/view/kr-c5/)<a href="https://opcfoundation.org/products/view/kr-c5/" rel="nofollow noopener noreferrer" target="_blank"><sup>[11]</sup></a> for the KR C5 controller says it comes with KUKA.DeviceConnector, which shares robot data over OPC UA, a standard for machine data. KUKA's cloud service, [KUKA iiQoT](https://www.kuka.com/en-de/products/robot-systems/software/cloud-software/iiqot-robot-condition-monitoring)<a href="https://www.kuka.com/en-de/products/robot-systems/software/cloud-software/iiqot-robot-condition-monitoring" rel="nofollow noopener noreferrer" target="_blank"><sup>[12]</sup></a>, shows a whole fleet on one dashboard and logs changes to each robot's software and programs. Its Basic version is free.

iiQoT asks for KUKA System Software (KSS) 8.3 or higher. Neither source mentions the newer iiQKA.OS2 operating system, so ask KUKA what your controller supports. The iiQoT page describes no way to send robots work, and no API (a way for one program to talk to another).

### Sending a robot work

You need an add-on package that KUKA sells separately, such as [KUKA.Ethernet KRL](https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka-ethernet-krl)<a href="https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka-ethernet-krl" rel="nofollow noopener noreferrer" target="_blank"><sup>[13]</sup></a> or [KUKA.PLC mxAutomation](https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka,-d-,plc-mxautomation)<a href="https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka,-d-,plc-mxautomation" rel="nofollow noopener noreferrer" target="_blank"><sup>[14]</sup></a>. With Ethernet KRL you also need a KRL program on the controller written to act on what arrives. mxAutomation instead runs KUKA's own interpreter on the controller and takes its commands from a PLC.

### What we couldn't find

As of October 2026, KUKA's public pages show no REST API for the controller. That's the web-style interface most business software expects. We found no KUKA Python package either. [KUKA AMP](https://www.kuka.com/en-us/company/press/news/2026/03/kuka-amp-nvidia-gtc)<a href="https://www.kuka.com/en-us/company/press/news/2026/03/kuka-amp-nvidia-gtc" rel="nofollow noopener noreferrer" target="_blank"><sup>[15]</sup></a>, announced in March 2026 as an open API platform, has no public documentation that we could find.

## Where Tallyfy could fit

Launch a Tallyfy template and its steps become [tasks](/products/pro/tracking-and-tasks/tasks/) assigned to people, with [form fields](/products/pro/tracking-and-tasks/tasks/what-are-form-fields-in-tallyfy/) for readings and [approve or reject steps](/products/pro/tracking-and-tasks/tasks/what-types-of-tasks-can-i-create-with-tallyfy/) for decisions. Each running process keeps an [activity log](/products/pro/tracking-and-tasks/tracker-view/how-can-i-track-process-activities-on-tallyfy/) of what happened and who did it.

Linking that to a robot means writing a small program of your own to sit between the two. Tallyfy doesn't supply one.

```d2
direction: down

Robot: KUKA controller {
  style.fill: "#f2faf4"
}
Bridge: Your own program {
  style.fill: "#e1f7e6"
}
Tallyfy: Tallyfy process {
  style.fill: "#e1f7e6"
}
Team: Your team {
  style.fill: "#f2faf4"
}

Robot -> Bridge: Reports status {
  style.stroke: "#225930"
}
Bridge -> Tallyfy: Launches a process {
  style.stroke: "#225930"
}
Tallyfy -> Team: Assigns tasks {
  style.stroke: "#225930"
}
Team -> Tallyfy: Completes tasks {
  style.stroke: "#225930"
}
Tallyfy -> Bridge: Sends a webhook {
  style.stroke: "#225930"
}
Bridge -> Robot: Passes job data {
  style.stroke: "#225930"
  style.stroke-dash: 3
}
```

- The solid arrows use what exists today: OPC UA from KUKA, and from Tallyfy the [API](/products/pro/integrations/open-api/) and the webhook (a message Tallyfy [sends to another system](/products/pro/integrations/webhooks/) when a task is completed).
- The dashed arrow needs a KUKA add-on package, and with Ethernet KRL a robot program written for it.

Start with reading only. Your program watches for a fault or a finished job and [launches a Tallyfy process](/products/pro/integrations/open-api/code-samples/processes/launch-process/), so the follow-up lands with the right person.

### Controllers and system software

- KUKA's [controller page](https://www.kuka.com/en-de/products/robot-systems/robot-controllers)<a href="https://www.kuka.com/en-de/products/robot-systems/robot-controllers" rel="nofollow noopener noreferrer" target="_blank"><sup>[16]</sup></a> lists the KR C5 and KR C5 micro, both for iiQKA.OS2, as of October 2026. The [KR C2 generation is discontinued](https://www.kuka.com/en-us/products/robotics-systems/2022-robot-upgrade-program)<a href="https://www.kuka.com/en-us/products/robotics-systems/2022-robot-upgrade-program" rel="nofollow noopener noreferrer" target="_blank"><sup>[17]</sup></a>.
- [iiQKA.OS2](https://www.kuka.com/en-de/products/robot-systems/software/system-software/iiqkaos2-operating-system-industrial-robots)<a href="https://www.kuka.com/en-de/products/robot-systems/software/system-software/iiqkaos2-operating-system-industrial-robots" rel="nofollow noopener noreferrer" target="_blank"><sup>[18]</sup></a> is KUKA's Linux-based robot operating system, with a web-based user interface and a virtual robot controller. It builds on KUKA's older system software, KSS.
- An optional NVIDIA expansion board adds AI for vision on the KR C5 and KR C5 micro, according to KUKA's [launch notice](https://www.kuka.com/en-de/company/press/news/2025/03/iiqka_os2-launch)<a href="https://www.kuka.com/en-de/company/press/news/2025/03/iiqka_os2-launch" rel="nofollow noopener noreferrer" target="_blank"><sup>[19]</sup></a>.
- The [OPC Foundation listing](https://opcfoundation.org/products/view/kr-c5/)<a href="https://opcfoundation.org/products/view/kr-c5/" rel="nofollow noopener noreferrer" target="_blank"><sup>[20]</sup></a> was published in 2022 and last certified in March 2026. It also covers the KR C4 on KSS 8.3 or higher. Ask KUKA whether the OPC UA server needs its own license.

### Robot programs and tools

- Robots on [KUKA System Software](https://www.kuka.com/en-de/products/robot-systems/software/system-software/kuka_systemsoftware)<a href="https://www.kuka.com/en-de/products/robot-systems/software/system-software/kuka_systemsoftware" rel="nofollow noopener noreferrer" target="_blank"><sup>[21]</sup></a> and iiQKA.OS2 are programmed in KRL, the KUKA Robot Language. KSS fieldbuses such as PROFINET and EtherCAT are set up and mapped in KUKA.WorkVisual.
- [Wikipedia](https://en.wikipedia.org/wiki/KUKA_Robot_Language)<a href="https://en.wikipedia.org/wiki/KUKA_Robot_Language" rel="nofollow noopener noreferrer" target="_blank"><sup>[22]</sup></a> calls KRL similar to Pascal. Each program is a `.src` file of movement commands and a `.dat` file of data with the same name.
- Programs sit in the controller's `KRC:\R1\Program` folder, according to a [public driver guide](https://github.com/ros-industrial/kuka_experimental/blob/melodic-devel/kuka_rsi_hw_interface/krl/KR_C4/README.md)<a href="https://github.com/ros-industrial/kuka_experimental/blob/melodic-devel/kuka_rsi_hw_interface/krl/KR_C4/README.md" rel="nofollow noopener noreferrer" target="_blank"><sup>[23]</sup></a>.
- Projects reach the controller over the network from KUKA.WorkVisual on KSS, or iiQWorks.Sim on iiQKA.OS2, according to a [ROS 2 driver guide](https://github.com/kuka-ros/kuka_drivers/blob/master/kuka_drivers/doc/1_RSI.md)<a href="https://github.com/kuka-ros/kuka_drivers/blob/master/kuka_drivers/doc/1_RSI.md" rel="nofollow noopener noreferrer" target="_blank"><sup>[24]</sup></a>.
- You can also program on a [teach pendant](https://www.kuka.com/en-de/products/robot-systems/robot-controllers/smartpad-robot-teach-pendant)<a href="https://www.kuka.com/en-de/products/robot-systems/robot-controllers/smartpad-robot-teach-pendant" rel="nofollow noopener noreferrer" target="_blank"><sup>[25]</sup></a>. KUKA lists the smartPAD pro and smartPLUG for iiQKA.OS2, and the smartPAD for KSS.
- [iiQWorks.Sim](https://www.kuka.com/en-de/products/robot-systems/software/planning-project-engineering-service-safety/iiqworks-sim-robot-simulation-software)<a href="https://www.kuka.com/en-de/products/robot-systems/software/planning-project-engineering-service-safety/iiqworks-sim-robot-simulation-software" rel="nofollow noopener noreferrer" target="_blank"><sup>[26]</sup></a> covers simulation and virtual commissioning.
- [ready2_pilot](https://www.kuka.com/ready2-pilot)<a href="https://www.kuka.com/ready2-pilot" rel="nofollow noopener noreferrer" target="_blank"><sup>[27]</sup></a> is a wireless add-on for guiding a robot by hand with a 6D mouse.
- The [LBR iiwa](https://www.kuka.com/en-de/products/robot-systems/industrial-robots/lbr-iiwa)<a href="https://www.kuka.com/en-de/products/robot-systems/industrial-robots/lbr-iiwa" rel="nofollow noopener noreferrer" target="_blank"><sup>[28]</sup></a> has its own controller, the KUKA Sunrise Cabinet.

### Ways to send work to a robot

KUKA sells each of these as an option. We found no public prices.

- **[KUKA.Ethernet KRL](https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka-ethernet-krl)<a href="https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka-ethernet-krl" rel="nofollow noopener noreferrer" target="_blank"><sup>[29]</sup></a>** - XML or binary data over TCP/IP or UDP, with up to 16 connections at once. The iiQKA.OS2 page calls its version iiQKA.EthernetKRL.
- **[KUKA.PLC mxAutomation](https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka,-d-,plc-mxautomation)<a href="https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka,-d-,plc-mxautomation" rel="nofollow noopener noreferrer" target="_blank"><sup>[30]</sup></a>** - a PLC commands the robot through function blocks and gets status back. KUKA lists Siemens, Rockwell and other makers.
- **[KUKA.RobotSensorInterface](https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka_robotsensorinterface)<a href="https://www.kuka.com/en-de/products/robot-systems/software/hub-technologies/kuka_robotsensorinterface" rel="nofollow noopener noreferrer" target="_blank"><sup>[31]</sup></a>** - real-time influence over motion, processed within 4 ms. It's a tool for motion engineers. The open-source [ROS 2 drivers](https://github.com/kuka-ros/kuka_drivers)<a href="https://github.com/kuka-ros/kuka_drivers" rel="nofollow noopener noreferrer" target="_blank"><sup>[32]</sup></a> build on it, though we couldn't confirm that KUKA runs that GitHub organization.
- **Fieldbus signals** - a line PLC starts a program number and reads back done and fault signals. Fieldbus hardware is [optional on the KR C5 micro](https://www.kuka.com/en-de/products/robot-systems/robot-controllers/kr-c5-micro-2_controller_small_robots)<a href="https://www.kuka.com/en-de/products/robot-systems/robot-controllers/kr-c5-micro-2_controller_small_robots" rel="nofollow noopener noreferrer" target="_blank"><sup>[33]</sup></a>.

KUKA's mobile robots take orders another way. The [KMP 250P](https://www.kuka.com/en-us/company/press/news/2025/08/the-new-kmp-250p)<a href="https://www.kuka.com/en-us/company/press/news/2025/08/the-new-kmp-250p" rel="nofollow noopener noreferrer" target="_blank"><sup>[34]</sup></a> platform is controlled through the KUKA.AMR Fleet manager and the VDA 5050 standard.

KUKA's manuals are in [KUKA Xpert](https://www.kuka.com/en-de/products/robot-systems/software/cloud-software/kuka-xpert)<a href="https://www.kuka.com/en-de/products/robot-systems/software/cloud-software/kuka-xpert" rel="nofollow noopener noreferrer" target="_blank"><sup>[35]</sup></a>, free with a my.KUKA account.

:::note[Integration status]
Tallyfy has no integration or partnership with Universal Robots, and there's no Tallyfy URCap (the add-on format these robots use). This page describes a concept. It isn't a product, and your own developer would have to build it. Facts about Universal Robots come from its public pages, read in October 2026.
:::

## How Tallyfy could work with Universal Robots

Universal Robots makes collaborative robot arms, often called cobots, and announced its newest generation in [September 2026](https://www.universal-robots.com/news-and-media/news-center/universal-robots-unveils-gen-7-new-platform-industrial-automation-physical-ai/)<a href="https://www.universal-robots.com/news-and-media/news-center/universal-robots-unveils-gen-7-new-platform-industrial-automation-physical-ai/" rel="nofollow noopener noreferrer" target="_blank"><sup>[1]</sup></a>. Outside software can load a program on one of these arms, [start and stop it](https://docs.universal-robots.com/PolyScopeX_SDK_Documentation/build/SDK-v0.22/Resources.html)<a href="https://docs.universal-robots.com/PolyScopeX_SDK_Documentation/build/SDK-v0.22/Resources.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[2]</sup></a>, and read what the robot is doing.

So a robot job could be one step in a longer procedure that people run in Tallyfy. A person finishes a check, the robot runs, and someone signs off the result. Tallyfy doesn't build or ship the link to the robot. Your developer would write it.

## What Universal Robots sells today

As of October 2026, the company's [FAQ](https://www.universal-robots.com/insights/faq/)<a href="https://www.universal-robots.com/insights/faq/" rel="nofollow noopener noreferrer" target="_blank"><sup>[3]</sup></a> describes three families of arm. The number after the dash in each name is the reach in millimetres.

- **e-Series**, from 2018. The [UR3e-540](https://www.universal-robots.com/products/ur3e-540/)<a href="https://www.universal-robots.com/products/ur3e-540/" rel="nofollow noopener noreferrer" target="_blank"><sup>[4]</sup></a> carries 3 kg, the [UR7e-920](https://www.universal-robots.com/products/ur7e-920/)<a href="https://www.universal-robots.com/products/ur7e-920/" rel="nofollow noopener noreferrer" target="_blank"><sup>[5]</sup></a> carries 7.5 kg and the [UR12e-1300](https://www.universal-robots.com/products/ur12e-1300/)<a href="https://www.universal-robots.com/products/ur12e-1300/" rel="nofollow noopener noreferrer" target="_blank"><sup>[6]</sup></a> carries 12.5 kg.
- **UR Series**, from 2022. The [UR20-1750](https://www.universal-robots.com/products/ur20-1750/)<a href="https://www.universal-robots.com/products/ur20-1750/" rel="nofollow noopener noreferrer" target="_blank"><sup>[7]</sup></a> carries 20 kg and the [UR30-1300](https://www.universal-robots.com/products/ur30-1300/)<a href="https://www.universal-robots.com/products/ur30-1300/" rel="nofollow noopener noreferrer" target="_blank"><sup>[8]</sup></a> carries 30 kg.
- **[g-Series](https://www.universal-robots.com/products/g-series/)<a href="https://www.universal-robots.com/products/g-series/" rel="nofollow noopener noreferrer" target="_blank"><sup>[9]</sup></a>**, new in 2026. The UR10g-1750 carries 8 kg (10 kg extended), the UR17g-1300 carries 15 kg (17.5 kg extended) and the UR18g-950 carries 18 kg.

The FAQ also explains the names. The UR7e and UR12e were the UR5e and UR10e, and the UR20 and UR30 gained the reach in their names. Three recent arms, the UR8 Long, UR15 and UR18, are "mature" products as of October 2026. The g-Series replaced them, and they stay fully supported. The 16 kg [UR16e](https://www.universal-robots.com/products/ur16e-cb5/)<a href="https://www.universal-robots.com/products/ur16e-cb5/" rel="nofollow noopener noreferrer" target="_blank"><sup>[10]</sup></a> is still listed too.

The g-Series arrived with a new control box, the [CB7 Core](https://www.universal-robots.com/products/cb7-core/)<a href="https://www.universal-robots.com/products/cb7-core/" rel="nofollow noopener noreferrer" target="_blank"><sup>[11]</sup></a>. The FAQ says the control box decides whether a robot runs the older PolyScope 5 software or the current PolyScope X.

Universal Robots also offers [UR Connect](https://www.universal-robots.com/marketplace/products/01tP4000009ExhNIAS/)<a href="https://www.universal-robots.com/marketplace/products/01tP4000009ExhNIAS/" rel="nofollow noopener noreferrer" target="_blank"><sup>[12]</sup></a>, its own fleet service. It has a dashboard, remote access, software updates, and cloud backups of programs with version history. Approved add-ons are listed on the [UR Marketplace](https://www.universal-robots.com/marketplace/)<a href="https://www.universal-robots.com/marketplace/" rel="nofollow noopener noreferrer" target="_blank"><sup>[13]</sup></a>.

## What outside software can ask a robot to do

Universal Robots publishes its developer interfaces. Which one you use depends on the software generation.

| What outside software does | PolyScope 5 | PolyScope X |
|---|---|---|
| Loads, starts, pauses and stops a program, and reads state | [Dashboard Server](https://www.universal-robots.com/articles/ur/dashboard-server-e-series-port-29999/)<a href="https://www.universal-robots.com/articles/ur/dashboard-server-e-series-port-29999/" rel="nofollow noopener noreferrer" target="_blank"><sup>[14]</sup></a> | [Robot API](https://www.universal-robots.com/articles/ur/release-notes/release-note-software-version-1011x/)<a href="https://www.universal-robots.com/articles/ur/release-notes/release-note-software-version-1011x/" rel="nofollow noopener noreferrer" target="_blank"><sup>[15]</sup></a>, which replaced it and works only in Remote Mode |
| Streams live robot data, up to 500 times a second | [RTDE](https://docs.universal-robots.com/tutorials/communication-protocol-tutorials/rtde-guide.html)<a href="https://docs.universal-robots.com/tutorials/communication-protocol-tutorials/rtde-guide.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[16]</sup></a> | Same |
| Sends URScript, the robot's programming language | [Primary and secondary interfaces](https://docs.universal-robots.com/tutorials/communication-protocol-tutorials/primary-secondary-guide.html)<a href="https://docs.universal-robots.com/tutorials/communication-protocol-tutorials/primary-secondary-guide.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[17]</sup></a>, [interpreter mode](https://www.universal-robots.com/articles/ur/programming/interpreter-mode/)<a href="https://www.universal-robots.com/articles/ur/programming/interpreter-mode/" rel="nofollow noopener noreferrer" target="_blank"><sup>[18]</sup></a> | Same |
| Answers calls from a running robot program | [XML-RPC](https://docs.universal-robots.com/tutorials/communication-protocol-tutorials/xmlrpc-communication.html)<a href="https://docs.universal-robots.com/tutorials/communication-protocol-tutorials/xmlrpc-communication.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[19]</sup></a>, [sockets](https://docs.universal-robots.com/PolyScopeX_SDK_Documentation/build/SDK-v0.22/_static/pdf/scriptManualG5.pdf)<a href="https://docs.universal-robots.com/PolyScopeX_SDK_Documentation/build/SDK-v0.22/_static/pdf/scriptManualG5.pdf" rel="nofollow noopener noreferrer" target="_blank"><sup>[20]</sup></a> | Same |
| Installs its own code on the controller | [URCap written in Java](https://docs.universal-robots.com/tutorials/ps5-urcap-tutorials/urcap-key-methods-principles.html)<a href="https://docs.universal-robots.com/tutorials/ps5-urcap-tutorials/urcap-key-methods-principles.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[21]</sup></a> | [URCap with a web front end](https://docs.universal-robots.com/PolyScopeX_SDK_Documentation/build/SDK-v0.22/UserGuide.html)<a href="https://docs.universal-robots.com/PolyScopeX_SDK_Documentation/build/SDK-v0.22/UserGuide.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[22]</sup></a> and an optional container |

PolyScope 5's long-term support release has an end date. As of October 2026, it's [supported until the end of 2027](https://www.universal-robots.com/articles/ur/documentation/product-notice-introduction-of-polyscope-526-long-term-support-lts/)<a href="https://www.universal-robots.com/articles/ur/documentation/product-notice-introduction-of-polyscope-526-long-term-support-lts/" rel="nofollow noopener noreferrer" target="_blank"><sup>[23]</sup></a>, and hardware introduced after that release isn't supported on it. The [upgrade guide](https://www.universal-robots.com/articles/ur/documentation/upgrading-from-a-polyscope-5-controller-to-a-polyscope-x-controller/)<a href="https://www.universal-robots.com/articles/ur/documentation/upgrading-from-a-polyscope-5-controller-to-a-polyscope-x-controller/" rel="nofollow noopener noreferrer" target="_blank"><sup>[24]</sup></a>, dated November 2024, says there's no direct migration to PolyScope X: programs and settings have to be redefined, and URCaps aren't reusable.

Two more limits apply:

- On PolyScope X, outside services start switched off, and an administrator can [switch each one on or off](https://www.universal-robots.com/articles/ur/release-notes/release-note-software-version-107x/)<a href="https://www.universal-robots.com/articles/ur/release-notes/release-note-software-version-107x/" rel="nofollow noopener noreferrer" target="_blank"><sup>[25]</sup></a>.
- Safety stays with the robot. Universal Robots says real-time control and certified safety [remain enforced by the robot](https://www.universal-robots.com/products/physical-ai/)<a href="https://www.universal-robots.com/products/physical-ai/" rel="nofollow noopener noreferrer" target="_blank"><sup>[26]</sup></a>.

## Where a written procedure fits

Tallyfy holds the steps people follow around the robot. A [template](/products/pro/documenting/templates/) is the written procedure, such as a changeover checklist, a first-part inspection or a weekly maintenance round. Each launch creates a [process](/products/pro/tracking-and-tasks/processes/) with tasks for named people, deadlines, and form fields for readings and sign-offs. Robot programs stay on the robot and in tools such as UR Connect.

Three things Tallyfy already does make a link possible:

- Another system can [launch a process through the API](/products/pro/launching/triggers/via-api/)[^1] and pre-fill its kick-off form.
- Tallyfy sends a [webhook](/products/pro/integrations/webhooks/)[^2] when a task is completed or a process launches.
- Every process has an [activity log](/products/pro/tracking-and-tasks/tracker-view/how-can-i-track-process-activities-on-tallyfy/) of who did what, and keeps the template version it launched with.

Here's how the concept could run. An operator completes a "cell is clear" task. The webhook reaches your developer's code, which asks the robot to load and start a stored program. When the program finishes, that code completes the next Tallyfy task through the API.

```d2
# Concept only: your own code links a Tallyfy process to a UR robot
direction: down

Check: Tallyfy task completed {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Listen: Your code gets webhook {
  style.fill: "#f2faf4"
  style.stroke: "#225930"
  style.stroke-dash: 3
}

Run: UR robot runs program {
  style.fill: "#f2faf4"
  style.stroke: "#225930"
  style.stroke-width: 2
}

Read: Your code reads result {
  style.fill: "#f2faf4"
  style.stroke: "#225930"
  style.stroke-dash: 3
}

Next: Next Tallyfy task done {
  style.fill: "#e1f7e6"
  style.stroke: "#225930"
}

Check -> Listen: Sends webhook
Listen -> Run: Loads and starts
Run -> Read: Reports state
Read -> Next: Calls Tallyfy API
```

**What to notice:**

- The dashed boxes are your own code. Tallyfy doesn't ship it.
- Tallyfy never talks to the robot directly.
- The robot keeps its own program and safety functions.

## For developers

*(Skip this unless you're setting up the technical side.)*

A few more facts for whoever writes the code:

- **ROS 2.** An [open-source driver](https://docs.universal-robots.com/Universal_Robots_ROS_Documentation/rolling/index.html)<a href="https://docs.universal-robots.com/Universal_Robots_ROS_Documentation/rolling/index.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[27]</sup></a> controls an arm from an outside ROS 2 application. PolyScope X has [ROS 2 built in](https://docs.universal-robots.com/polyscopex-ros2/latest/index.html)<a href="https://docs.universal-robots.com/polyscopex-ros2/latest/index.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[28]</sup></a>, and its ROS 2 documentation covers version 10.13 and later.
- **Files.** Program and script files can be copied to the robot over [FTP, SFTP or SSH](https://docs.universal-robots.com/tutorials/urscript-tutorials/ftp.html)<a href="https://docs.universal-robots.com/tutorials/urscript-tutorials/ftp.html" rel="nofollow noopener noreferrer" target="_blank"><sup>[29]</sup></a>. A PolyScope program is a `.urp` file, which a Universal Robots staff member described in 2017 as [compressed XML](https://forum.universal-robots.com/t/simulator-to-robot-programming-workflow/591)<a href="https://forum.universal-robots.com/t/simulator-to-robot-programming-workflow/591" rel="nofollow noopener noreferrer" target="_blank"><sup>[30]</sup></a>. PolyScope X can be used for offline programming from any device with a browser, and it can [export a whole application as one file](https://www.universal-robots.com/products/polyscope-x/)<a href="https://www.universal-robots.com/products/polyscope-x/" rel="nofollow noopener noreferrer" target="_blank"><sup>[31]</sup></a>.
- **Factory networks.** PolyScope 5 lists [Modbus, PROFIsafe and EtherNet/IP](https://www.universal-robots.com/products/polyscope-5/)<a href="https://www.universal-robots.com/products/polyscope-5/" rel="nofollow noopener noreferrer" target="_blank"><sup>[32]</sup></a>. The [CB7 Core page](https://www.universal-robots.com/products/cb7-core/)<a href="https://www.universal-robots.com/products/cb7-core/" rel="nofollow noopener noreferrer" target="_blank"><sup>[33]</sup></a> lists Modbus, EtherNet/IP, PROFINET and OPC UA.
- **Port 80.** From PolyScope X 10.14 it's [closed by default](https://www.universal-robots.com/articles/ur/release-notes/release-note-software-version-1014x/)<a href="https://www.universal-robots.com/articles/ur/release-notes/release-note-software-version-1014x/" rel="nofollow noopener noreferrer" target="_blank"><sup>[34]</sup></a>, so a URCap that outside systems reach on that port needs it switched back on.

The Tallyfy side is ordinary API work. Your code can [launch a process](/products/pro/integrations/open-api/code-samples/processes/launch-process/) when a robot program stops, or [complete a task](/products/pro/integrations/open-api/code-samples/tasks/complete-task/) when one finishes. Those two pages have working code samples.

[^1]: Application programming interface, the documented way one program asks another to do something.
[^2]: A message Tallyfy sends to a web address you choose, the moment an event happens in a process.

If you don't have one, sign up at [chatgpt.com](https://chatgpt.com)<a href="https://chatgpt.com" rel="nofollow noopener noreferrer" target="_blank"><sup>[1]</sup></a> first.

## What gets installed

Tallyfy Desktop drives Codex through OpenAI's official `codex` command-line tool (the `@openai/codex` npm package). Each time it starts, the desktop app checks whether `codex` is on your `PATH` and whether you've signed in. If either is missing, Codex shows as "(not installed)" in the **Provider** dropdown of the **AI Chat** tab, with an **Install** button beside it.

The install command per platform is baked into the desktop app source code:

| Platform | Command |
|---|---|
| macOS | `npm install -g @openai/codex` |
| Linux | `npm install -g @openai/codex` |
| Windows | `npm install -g @openai/codex` |

The binary lands in your global npm prefix (typically `/opt/homebrew/bin/codex` on macOS-arm64 with Homebrew, or `/usr/local/bin/codex` with classic npm). You'll need Node.js 18+ already installed.

## Prerequisites

- A Tallyfy account (you'll sign in to Tallyfy Desktop first)
- A ChatGPT Plus, Pro, Business, Enterprise, or Edu subscription
- Node.js 18 or higher with `npm` available on `PATH`
- A modern web browser for the OAuth sign-in step

## Option A: Install Wizard (recommended)

<Steps>

1. **Pick Codex in the AI Chat tab**

   In Tallyfy Desktop, open the **AI Chat** tab and choose **Codex** from the **Provider** dropdown. If Codex isn't ready to use, it shows as "Codex (not installed)" with an **Install** button beside the dropdown. Click **Install** to open the Install Wizard.

2. **Read the consent screen**

   The wizard shows the exact npm command and its risks:
   - Modifies your global npm prefix
   - May require `sudo` if your npm prefix is system-owned (uncommon with Homebrew or nvm)
   - After install, you must run `codex login` interactively before headless use; otherwise calls return HTTP 401

3. **Hold Shift and click Install**

   The **Install** button works only while you hold Shift. Until then it reads **Hold Shift to enable**. To back out instead, click **Cancel**.

4. **Watch the progress log**

   The wizard streams `npm install` output, then runs `codex --version` to check the install. When the check passes, it shows "Installed Codex:" followed by the version. Click **Continue** to close the wizard.

5. **Sign in with ChatGPT**

   The wizard doesn't sign you in. Open a terminal and run `codex login`, which opens OpenAI's OAuth flow in your default browser. Approve the connection and return to the terminal.

   The token is stored under `~/.codex/auth.json`. The desktop app checks for that file to see whether you're signed in.

6. **Restart and test the connection**

   Quit and reopen Tallyfy Desktop so it detects Codex. In the **AI Chat** tab, choose **Codex**, type `hi`, and click **Send** (or press Cmd+Enter on macOS, Ctrl+Enter on Windows and Linux). You should see Codex's streamed response within a few seconds.

</Steps>

## Option B: Manual install

<Steps>

1. **Install via npm**

   ```bash
   npm install -g @openai/codex
   ```

   If npm reports a permission error, your npm prefix is likely system-owned. Either reconfigure npm to use a user-owned prefix (recommended; see [npm docs](https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally)<a href="https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally" rel="nofollow noopener noreferrer" target="_blank"><sup>[2]</sup></a>) or run with `sudo`. Tallyfy Desktop never uses `sudo`; the wizard fails cleanly in that case.

2. **Sign in**

   ```bash
   codex login
   ```

   This opens OpenAI's OAuth flow in your browser. Approve and return to the terminal.

3. **Restart Tallyfy Desktop**

   Quit fully and reopen. Codex no longer shows "(not installed)" in the **Provider** dropdown.

</Steps>

## First chat

Once Codex is connected:

1. Open the **AI Chat** tab and choose **Codex** from the **Provider** dropdown.
2. The **Model** dropdown starts on **(default)**, which leaves the model choice to the Codex CLI. You can also pick **GPT-5 Codex**.
3. Type your message and click **Send**. Codex streams plain-text responses, so you'll see the text appear line by line.

Tallyfy Desktop doesn't connect Codex to MCP servers, so the [Tallyfy MCP server](/products/pro/integrations/mcp-server/) isn't auto-injected. Codex gets no Tallyfy context and can't read or change your Tallyfy data. The desktop app sends it only your prompt and the model you picked. You can still trigger the [Task Intent Widget](/products/pro/integrations/tallyfy-desktop-ai/task-intent-widget/) from Codex chats; the widget watches for intent in the text Codex generates.

## Verifying the install yourself

```bash
# Is the binary on PATH?
which codex

# Does it run?
codex --version

# Are you signed in?
test -f ~/.codex/auth.json && echo "signed in" || echo "not signed in"
```

The desktop app keeps each detection result for 60 minutes and checks again every time it starts, so quit and reopen it after an install or sign-in.

## Troubleshooting

### `npm install` fails with EACCES

Your npm prefix is system-owned. The two clean fixes are:

1. **Switch to a user-owned prefix** (recommended): see [npm's official fix](https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally)<a href="https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally" rel="nofollow noopener noreferrer" target="_blank"><sup>[3]</sup></a>. After reconfiguring, re-run the wizard.
2. **Use nvm** to manage Node.js: nvm puts npm in your home directory, sidestepping the issue. Install nvm from [nvm-sh/nvm](https://github.com/nvm-sh/nvm)<a href="https://github.com/nvm-sh/nvm" rel="nofollow noopener noreferrer" target="_blank"><sup>[4]</sup></a>, then reinstall Node.js via `nvm install 20`.

Don't run the wizard with `sudo`; the desktop app won't do that for you and it creates permission problems later.

### "HTTP 401 Unauthorized" in the chat

You haven't run `codex login` yet, or the OAuth token expired. From a terminal:

```bash
codex login
```

Approve in the browser. Then quit and reopen Tallyfy Desktop, and send your prompt again.

### Codex hangs and produces no output

Codex's CLI treats open stdin as input to append to the prompt; without proper stdin redirection it can wait forever. Tallyfy Desktop closes stdin when it starts Codex, so you shouldn't hit this from inside the app. If you do, click **Cancel** and send the prompt again.

### Codex shows as installed but won't chat

Run `codex doctor` in a terminal. It reports the auth state, the model availability, and any account-level restrictions. If it says "authenticated, no model access," your ChatGPT plan doesn't include API access; upgrade to Plus, Pro, or higher.

## What Codex covers in v2.0.0

| Capability | Status |
|---|---|
| Streaming text responses | Yes (plain text per line) |
| MCP tool use | No (Tallyfy Desktop doesn't connect Codex to MCP servers) |
| Cost reporting | No (Codex charges against your ChatGPT subscription, no per-call cost is surfaced) |
| Thinking events | No |
| File attachments | No |
| Browser automation | No |
| Tallyfy context injection | No (Codex gets only your prompt and the model you picked) |
| Task Intent Widget | Yes (regex-based detection on Codex output) |

If you need the AI to read or change your Tallyfy data, use Claude or Gemini instead. Both get the Tallyfy MCP server.

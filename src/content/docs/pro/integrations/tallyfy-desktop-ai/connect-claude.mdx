## What gets installed

Tallyfy Desktop drives Claude through Anthropic's official `claude` command-line tool (Claude Code). Each time it starts, the desktop app checks whether `claude` is on your `PATH` and whether you've signed in. If either is missing, Claude shows as "(not installed)" in the **Provider** dropdown of the **AI Chat** tab, with an **Install** button beside it.

The install command per platform is baked into the desktop app source code:

| Platform | Command |
|---|---|
| macOS | `curl -fsSL https://claude.ai/install.sh \| bash` |
| Linux | `curl -fsSL https://claude.ai/install.sh \| bash` |
| Windows | `powershell -Command "irm https://claude.ai/install.ps1 \| iex"` |

Binaries land under `~/.local/bin/` on macOS and Linux, and under `%LOCALAPPDATA%\claude\bin\` on Windows. No `sudo` or admin rights are required.

## Prerequisites

- A Tallyfy account (you'll sign in to Tallyfy Desktop first, before the **AI Chat** tab works)
- A Claude.ai subscription on Pro, Max, Team, or Enterprise plan
- A modern web browser for the OAuth sign-in step (`claude login` opens it for you)

## Option A: Install Wizard (recommended)

This is the path the desktop app guides you through. The wizard shows the exact command before it runs and asks for an explicit consent gesture.

<Steps>

1. **Pick Claude in the AI Chat tab**

   In Tallyfy Desktop, open the **AI Chat** tab and choose **Claude** from the **Provider** dropdown. If Claude isn't ready to use, it shows as "Claude (not installed)" with an **Install** button beside the dropdown. Click **Install** to open the Install Wizard.

2. **Read the consent screen**

   The wizard shows:
   - The provider being installed (Claude, Anthropic)
   - The exact command that will run (the `curl ... | bash` line for your platform)
   - The command's SHA256 digest, which the app checks again before it runs anything
   - A risks list (downloads a script from `claude.ai` over HTTPS, writes binaries under `~/.local/bin/`, doesn't touch `/usr/local`, `/etc`, or system services)
   - An **Install** button that reads **Hold Shift to enable** until you press Shift

   ![Install Wizard with the consent screen for Claude](https://screenshots.tallyfy.com/desktop-ai/install-wizard-consent.png)

3. **Hold Shift and click Install**

   The **Install** button works only while you hold the Shift key, so an install can't start by accident. Hold Shift and click **Install**. To back out instead, click **Cancel**.

4. **Watch the progress log**

   The wizard streams the installer's output in real time, first under **Installing**, then under **Verifying install**.

   ![Install Wizard with the progress log showing a successful Claude install](https://screenshots.tallyfy.com/desktop-ai/install-wizard-progress.png)

5. **Verify**

   The wizard runs `claude --version` and shows the result as "Installed Claude:" followed by the version. If you see a version number, the binary works. Click **Continue** to close the wizard.

6. **Sign in with Claude.ai**

   The wizard doesn't sign you in. Open a terminal and run `claude login`. It opens Claude's OAuth flow in your default browser. Approve the connection. The browser will redirect back to a confirmation page; close it when prompted.

   The token is stored under `~/.claude/.credentials.json` (and in macOS Keychain on Darwin systems). The desktop app checks for that file to see whether you're signed in; you don't paste the token anywhere.

7. **Restart and test the connection**

   Quit and reopen Tallyfy Desktop so it detects Claude. In the **AI Chat** tab, choose **Claude**, type `hi`, and click **Send** (or press Cmd+Enter on macOS, Ctrl+Enter on Windows and Linux). You should see Claude's streamed response within a few seconds. The terminal panel under the chat names the provider and model when the run starts.

</Steps>

## Option B: Manual install

If you'd rather install Claude outside the desktop app, that works too. Tallyfy Desktop only checks whether `claude` is on `PATH`; it doesn't care how it got there.

<Steps>

1. **Install the Claude CLI**

   Open a terminal and run:

   - **macOS / Linux**: `curl -fsSL https://claude.ai/install.sh | bash`
   - **Windows (PowerShell)**: `irm https://claude.ai/install.ps1 | iex`

2. **Sign in**

   In the same terminal: `claude login`

   This opens Claude's OAuth flow in your browser. Approve and return to the terminal.

3. **Restart Tallyfy Desktop**

   Quit the app fully (Cmd+Q on macOS, File then Quit on Windows/Linux) and reopen it. Claude no longer shows "(not installed)" in the **Provider** dropdown, and the **Install** button goes away.

</Steps>

## First chat

Once Claude is connected:

1. Open the **AI Chat** tab and choose **Claude** from the **Provider** dropdown.
2. The **Model** dropdown starts on **(default)**, which leaves the model choice to the Claude CLI. You can pick **Claude Opus 5.5**, **Claude Sonnet 5.5**, or **Claude Haiku 5.5** instead.
3. Type your message and click **Send** (or press Cmd+Enter on macOS, Ctrl+Enter on Windows and Linux). Enter on its own adds a new line. You'll see the streamed response appear chunk by chunk.
4. When the run ends, its cost shows in the [Terminal Jobs](/products/pro/integrations/tallyfy-desktop-ai/terminal-jobs/) tab.

Because the [Tallyfy MCP server](/products/pro/integrations/mcp-server/) is auto-injected, Claude already knows about your tasks, processes, templates, and team. Try:

- "Show me all my open tasks"
- "Find the customer onboarding template"
- "Create a task to review next quarter's hiring plan, due Friday"

If Claude's reply to that last one says it will create the task, the [Task Intent Widget](/products/pro/integrations/tallyfy-desktop-ai/task-intent-widget/) shows under the reply with a button to create it in Tallyfy.

## Verifying the install yourself

If something feels off, you can check the same things the desktop app checks:

```bash
# Is the binary on PATH?
which claude

# Does it run?
claude --version

# Are you signed in?
test -f ~/.claude/.credentials.json && echo "signed in" || echo "not signed in"
```

The desktop app keeps each detection result for 60 minutes and checks again every time it starts. After an install or sign-in, quit and reopen Tallyfy Desktop so it picks up the change.

## Troubleshooting

### "`claude` binary not found" after install

The installer writes to `~/.local/bin/` (or `%LOCALAPPDATA%\claude\bin\` on Windows), which isn't always on the default `PATH`. Add it:

- **macOS / Linux**: `echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc` (or `~/.bashrc`), then restart Tallyfy Desktop.
- **Windows**: open System Properties, click Environment Variables, add `%LOCALAPPDATA%\claude\bin` to your user `Path`.

Then quit and reopen Tallyfy Desktop so it checks again.

### OAuth browser window doesn't open

Some browsers block windows that other apps open. Quit the browser, reopen it, then run `claude login` again in a terminal.

### "Permission denied" on macOS

If the install script can't write to `~/.local/bin/`, your shell might be sandboxed. Try running the install command directly in Terminal.app rather than via the wizard. If `chmod` errors appear, run `chmod +w ~/.local/bin/` and retry.

### Quota or rate-limit errors mid-chat

Claude's per-account quota varies by plan. If you hit a quota wall, the streamed response stops and an error event appears in the chat. Wait a few minutes and retry, or upgrade your Claude.ai plan. Tallyfy Desktop doesn't add quota on top of Anthropic's; the limit is whatever your subscription says.

### Claude still shows "(not installed)"

Tallyfy Desktop checks for the CLI and your sign-in when it starts. Quit and reopen it after you install or run `claude login`. If Claude still shows "(not installed)", run the checks under [Verifying the install yourself](#verifying-the-install-yourself).

## What Claude can do that the others can't

Claude is the most capable provider in Tallyfy Desktop v2.0.0:

- **Tool use** - Claude can call MCP tools (Tallyfy's auto-injected MCP server) while it answers. Each call shows in the chat as a card with the tool's name and status; open it to see the input and output.
- **Thinking** - Claude streams its reasoning in a separate channel. It shows in the chat as a **Thinking** section, collapsed until you open it.
- **Cost reporting** - Claude reports the cost of each run in US dollars when it finishes, and Terminal Jobs shows it.
- **Browser automation** - turn on the **Chrome** switch in the **AI Chat** tab and Claude runs with the `claude --chrome` flag, which drives a real Chrome browser through the Claude for Chrome extension. The desktop repo is private, but its `docs/COMPUTER-USE-DEFERRED.md` covers what this can and can't do. Ask support if you need the detail.

The other providers cover subsets of these. Each of their connect guides ends with a table of what that provider supports, and the [overview](/products/pro/integrations/tallyfy-desktop-ai/) compares all four.

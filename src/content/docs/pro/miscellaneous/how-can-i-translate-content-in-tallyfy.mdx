## Translation options in Tallyfy

Tallyfy offers two translation features:

1.  **Interface language** - Change the display language for menus, buttons, and system text
2.  **Content translation** - Translate user-generated text using Microsoft Azure AI (requires admin setup)

See [global workplace language requirements](/products/pro/integrations/azure-translation/global-workplace-language-requirements/) to understand which countries mandate or recommend translation of process content like SOPs and employee handbooks.

### Change interface language

<Steps>
1. Click the globe icon in the top menu bar.
2. In the **App Language** section, click **Edit**, pick your language and click **Save**.
3. The interface switches to your selected language.
</Steps>

### Available interface languages

Tallyfy supports English, Spanish, French, German, Chinese, Japanese, and others.

### Administrator setup for content translation

Content translation uses Microsoft Azure Cognitive Services and supports 100+ languages.

#### Requirements

*   Active Microsoft Azure account with translation services enabled
*   The key, resource name and region of your Azure Translator resource
*   Administrator access in your Tallyfy organization

#### Configuration steps
*(See the [Azure setup guide](/products/pro/integrations/azure-translation/how-to-set-up-azure-cognitive-ai-integration/) for detailed Azure configuration.)*

<Steps>
1.  **Azure configuration** - Create a "Translator" service resource and note its key, its resource name (the name you gave it) and its region.
2.  **Tallyfy configuration** - Go to **Settings** > **Integrations**. In the **Translation** section, find the **Azure** card and click **Configure**.
3.  **Key** - Paste your Azure key into the **Key** field.
4.  **Resource name** - Enter the name of your Translator resource in the **Resource name** field.
5.  **Region** - Enter your Azure region in the **Region** field. All three fields are required.
6.  **Activation** - Click **Save**. Tallyfy tests the connection with Azure first and shows **Azure config failed** if the test fails.
</Steps>

### User access after setup

Once it's configured, everyone in your organization, guests included, can pick a content language from the globe icon.

### Using content translation

<Steps>
1. Click the globe icon in the top menu bar.
2. In the **Content Language** section, click **Edit**, pick the language you want content translated into and click **Save**.
3. The globe turns green when Azure is connected and your content language isn't **No Translation**. It pulses while a translation is in progress.
4. Tallyfy translates task titles, task descriptions, form field labels and document text into your selected language. Comments and form answers stay as written.
</Steps>

:::note[Translation limitations]
Real-time translation works best with standard business text. Highly technical terms, slang, or industry jargon might not translate accurately.

**RTL (Right-to-Left) support** - Tallyfy doesn't currently support RTL languages like Arabic or Hebrew for interface display. You can translate content to these languages, but the layout stays left-to-right.
:::

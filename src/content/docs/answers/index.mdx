## What Tallyfy Answers does

Tallyfy Answers is a hosted search service. You send it your content as JSON objects, and it searches them by meaning as well as by keyword.

It has four core capabilities:

* **Document storage** - Stores each JSON object with an AI embedding of its full content.
* **Hybrid search** - Combines meaning-based search with keyword matching in one query.
* **Recommendations** - Finds objects similar to one you name, among objects from the same source.
* **Batch processing** - Imports large sets of objects in the background.

Semantic search is part of the core service, so there's no separate add-on to set up.

:::note[Important distinction]
Tallyfy Answers works differently from search engines like Google or Bing.

Instead of crawling websites, you push JSON-formatted data directly into Tallyfy Answers. Your users then search through your specific data using a customized search interface on your site or app.
:::

Tallyfy sets up access to Answers for each customer. Schedule a discussion about it at https://tallyfy.com/amit

## Competitor comparison

Here's how Tallyfy Answers compares with other search technology:

### Key differentiators

| Feature | Tallyfy Answers | Elasticsearch | Algolia | TypeSense | Meilisearch |
|---------|----------------|--------------|---------|-----------|-------------|
| **Architecture** | Vector database with AI integration[^1] | Inverted index[^2] | Inverted index with AI features | Inverted index | Inverted index |
| **AI capabilities** | Optional AI overview of results, written by Claude | Limited, requires add-ons | NeuralSearch add-on | Limited | Limited |
| **Semantic search** | Built-in | Requires custom setup | Available as add-on | Limited | Limited |
| **Deployment complexity** | Low (fully managed) | High | Low | Medium | Medium |

### Strengths versus competitors

**Compared to Elasticsearch:**
- Tallyfy runs the service, so you don't set up servers or a search cluster.
- Semantic search and keyword search are both built in.
- Handles natural language queries out of the box.

**Compared to Algolia:**
- Search matches on meaning as well as on keywords.
- Semantic search is built into the core product (not an add-on).
- Unified vector and keyword search in a single query.

**Compared to TypeSense:**
- Conversational queries work because search is semantic.
- An optional AI overview from Claude summarizes the top results.

**Compared to Meilisearch:**
- Search with full sentences.

### Best suited use cases

Tallyfy Answers fits these uses:

1. **Content-rich applications** - Find answers in a large set of documents using natural language
2. **Customer support knowledge bases** - Users ask questions conversationally, and the optional AI overview gives a direct answer
3. **Product catalogs** - Search by features, benefits, or use cases (not just product names)
4. **Documentation sites** - Developers find code examples and explanations
5. **E-commerce platforms** - Shoppers describe what they want in their own words

Traditional search engines match keywords but miss the actual meaning behind queries. A user searching "how to reduce monthly costs" won't find an article titled "Budget optimization strategies" with keyword search alone.

Tallyfy Answers matches on both keywords and meaning, so a search can find a page that doesn't use the words the user typed.
